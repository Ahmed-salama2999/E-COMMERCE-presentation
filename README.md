# 📊 E-Commerce Business Intelligence Presentation

An interactive, high-end data visualization dashboard designed to showcase e-commerce performance metrics, financial insights, and strategic business analysis.

## ✨ Key Features:
- **Interactive Data Visualization:** Dynamic charts using `Chart.js` for sales trends, category performance, and supplier analysis.
- **Executive Summary:** High-level KPIs including Revenue, Gross Margin, and ROI.
- **Supply Chain Insights:** Analysis of supplier contributions and return rates.
- **Modern UI/UX:** A sleek, professional design with a premium aesthetic, optimized for executive presentations.
- **Fully Responsive:** Works seamlessly on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack:
- **Frontend:** HTML5, CSS3 (Custom Styles).
- **Data Engine:** JavaScript (ES6+).
- **Charts:** Chart.js Library.
- **Typography:** Premium Google Fonts (Playfair Display & DM Sans).
